# Laboratorio di TPSIT - Repository Personale

Questo repository raccoglie gli appunti, le esercitazioni e i progetti svolti durante le lezioni di laboratorio di TPSIT per l'anno scolastico 2026-2027.

## Descrizione del progetto

### Cos'è questo progetto?
Questo repository è lo spazio di lavoro principale per conservare e documentare tutto il materiale pratico del corso. Raccoglie gli appunti iniziali, gli esercizi di scrittura in Markdown e i progetti web che verranno sviluppati durante l'anno.

### A cosa serve?
Il progetto serve a imparare:
* L'uso di **Git** e **GitHub** per gestire e salvare il codice.
* La scrittura di documentazione tecnica in **Markdown**.
* La creazione di pagine web con **HTML** e **CSS**.
* La programmazione lato client con **JavaScript**.

## Come consultare e clonare il lavoro

Per scaricare una copia di questo repository sulla tua postazione locale, apri il terminale ed esegui il comando:

```bash
git clone https://github.com/alicetodeschi10/sito-tpsit.git
```


Una volta clonato il repository, puoi aprire la cartella con **Visual Studio Code** per consultare e modificare i file.

## Strumenti utilizzati

* **Git e GitHub:** Per la gestione delle versioni e la pubblicazione del lavoro online.
* **Visual Studio Code:** Come editor principale per scrivere codice e documenti.
* **Browser Web:** Per verificare il risultato del lavoro e fare il debug.

- [x] **M0:** Configurazione dell'ambiente di lavoro (Git, GitHub, VS Code)
