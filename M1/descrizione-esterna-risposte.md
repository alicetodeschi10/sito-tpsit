# Descrizione Esterna del Progetto

## Cos'è il progetto, a cosa serve e come si usa

### Cos'è
È la cartella di laboratorio di TPSIT della studentessa Alice. Contiene i suoi appunti e i suoi esercizi di scuola.

### A cosa serve
Serve a raccogliere i lavori fatti in classe per imparare a usare Git, GitHub, il linguaggio Markdown e a creare siti web (HTML, CSS e JavaScript).

### Come si usa
Si scarica sul computer da terminale con questo comando:
```bash
git clone https://github.com
```
Dopo averlo scaricato, si apre la cartella con Visual Studio Code per vedere i file.
