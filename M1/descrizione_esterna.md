# Descrizione esterna del progetto di Rebecca Frost

## Che cos'è
Questo è il repository di esercitazione creato da Rebecca Frost per il laboratorio di TPSIT (anno scolastico 2026/2027). Contiene file di testo, immagini e documenti in formato Markdown distribuiti nelle cartelle M0 ed M1.

## A cosa serve
Serve a raccogliere, organizzare e documentare il materiale didattico svolto in classe e a casa, mostrando l'avanzamento pratico nell'uso di Git, GitHub e dell'editor Visual Studio Code.

## Come si usa
Per consultare il lavoro sul proprio computer, si clona il repository da terminale usando il comando `git clone` con il link del progetto, per poi aprire la cartella ed esaminare i documenti con Visual Studio Code.
