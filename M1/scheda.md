# *WHEN WE ALL FALL ASLEEP, WHERE DO WE GO?*

* **Artista:** Billie Eilish
* **Anno di pubblicazione:** 2019

---

## Descrizione
when we all fall asleep, where do we go? è il primo album di Billie Eilish prodotto insieme a suo fratello Finneas. Questo album non parla solo di musica pop, ma esplora quello che proviamo quando siamo soli con i nostri pensieri più scuri attraverso metafore sull'insonnia e sugli incubi, Billie racconta la paura del futuro, l'ansia e la vulnerabilità di quando si cresce con un suono cupo ma intimo, le canzoni mostrano che è normale sentirsi giudicati o spaventati dalle proprie emozioni. È un disco che dà voce alle insicurezze che spesso si cerca di nascondere agli altri.

---

## Brani Principali
- **when the party's over:** Parla del dolore della fine di una relazione e del senso di vuoto che resta quando la festa o la compagnia si disperdono.
- **ilomilo:** Ispirato all'omonimo videogioco, descrive la paura paralizzante di perdere le persone care.
- **listen before i go:** Una canzone intensa e malinconica che tocca il tema dei pensieri suicidi e del desiderio di un ultimo saluto prima di farla finita.
- **i love you:** Racconta la paura di innamorarsi e l'ansia di trovarsi intrappolati in un sentimento troppo grande.

## Confronto fra le due rese
Confrontando il documento in locale con quello su GitHub si notano alcune cose.
La tabella si vede bene in entrambi i posti, anche se la grafica di GitHub è un po' più ordinata.
La casella di spunta su GitHub si vede in modo diverso rispetto a Visual Studio Code in cui si vedono allo stesso modo in cui le scrivi nel file cioè due parentesi graffe vuote o con una x dentro
Il problema vero lo fa l'immagine: se metti una lettera maiuscola nel nome del percorso per sbaglio, l'immagine si vede nell'anteprima di Visual Studio Code ma sparisce completamente su GitHub. Questo succede perché i server di GitHub usano Linux, un sistema che fa differenza tra maiuscole e minuscole, a differenza del computer locale. Una volta corretto il percorso scrivendo il nome del file in minuscolo esatto e rifatto il push, l'immagine torna a vedersi regolarmente online.
